# HR Analytics Dashboard | Power BI

## Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee data and provide insights into workforce demographics, employment types, departments, and training costs.

## Dashboard Preview


## Key Metrics
- **Total Employees:** 2,845
- **Total Training Cost:** 1.59M
- **Average Employee Age:** 49.45 years
- **Production Department:** Approximately 1,910 employees
- **Female Employees:** 55.82% of the workforce

## Key Insights
- The Production department represents approximately 67% of the total workforce.
- Female employees account for 55.82% of all employees.
- Full-Time, Contract, and Part-Time employment types have relatively similar distributions.
